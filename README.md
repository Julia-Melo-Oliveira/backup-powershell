

# Backup PowerShell

Projeto de automação simples em PowerShell para copiar arquivos de uma pasta de origem para uma pasta de destino, simulando um processo de backup.

## Como usar
1. Defina as pastas de origem e destino no script.
2. Execute o arquivo `backup.ps1` no PowerShell.
3. Os arquivos serão copiados automaticamente.

## Tecnologias
- PowerShell
- Windows
